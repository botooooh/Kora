# Kora — La Dynamic Island Vivante pour Windows (par Mr Paul) 🟢✨

**Kora** transforme le haut de votre écran Windows 10/11 en une **Dynamic Island** vivante, fluide et ultra-optimisée (~60 Mo RAM, 0% CPU au repos, conçu dès Intel Core i3 & 8 Go RAM).

## ✨ Fonctionnalités principales
- 👀 **Yeux Cyber-Visor Kora** (Palette Vert Émeraude `#00e676`, Cyber Lime `#a3ff12` & Or Solaire `#ffd000`).
- 🎵 **Musique & Paroles Synchronisées** : Compatible Apple Music, Spotify, YouTube via Windows Media Control + paroles temps réel (`lrclib.net`).
- 📋 **Presse-papiers Intelligent (`Ctrl+C`)** : Capture automatique de textes, liens, codes couleurs HEX et images.
- 📂 **Étagère Fichiers Drag & Drop (Entrant & Sortant)** : Glissez vos fichiers dans Kora et reglissez-les vers WhatsApp, Discord, l'Explorateur ou le Bureau.
- 📸 **Capture d'écran Furtive → Fichiers** : Kora est **100% invisible** sur vos captures d'écran (`Win+Shift+S`) et range automatiquement chaque capture dans l'étagère Fichiers.
- 🔊 **Animations Clavier** : Volume système, Luminosité écran et Microphone coupé (avec témoin lumineux rouge directement entre les yeux de Kora).
- 🖥️ **Rétractation & Plein Écran Intelligent** : Se rétracte en haut de l'écran et disparaît automatiquement quand une application (WhatsApp, vidéo, jeu) est en plein écran / maximisée.

## 🚀 Lancement rapide
1. Exécutez **`Kora.exe`** (ou `npm install && npm start` depuis les sources).
2. Passez votre souris tout en haut au centre de l'écran pour ouvrir **Kora**.
